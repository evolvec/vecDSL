# vecDSL coverage: Chroma

Server 1.5.9 (`chromadb/chroma:1.5.9`, HTTP 8000, data in `/data`), Python `chromadb-client` 1.5.9 to <1.6 (HTTP only), TypeScript `chromadb` 3.5.0, Java over the HTTP API with `java.net.http` and Gson 2.13.2 (Chroma publishes no Java client). Pins checked on 2026-11-11: 1.5.9 is the latest server tag and PyPI release (5 May 2026), 3.5.0 the npm `latest` (30 June 2026). Rows are generated from `model/generated/VecDSL.ecore`: every concrete Method, Concept, AlterOperation and ExtensionItem class, then every structural feature of each Method class. Status: native (one SDK or HTTP call), concealed (the runtime composes documented calls with the exact vecDSL semantics), unsupported (Chroma lacks it; the generator raises the message), not-applicable (cannot occur for Chroma). No row is pending: every native or concealed construct is generated. Runtime calls go through `vecdsl_chroma_runtime.py`, `vecdslChromaRuntime.ts` or `ChromaRuntime.java`. References point to the sources at the pinned tag; the OpenAPI operation is named in parentheses. The local server's behavior was also checked against `chroma run` 1.5.9 (MAPPING.md, "Server findings").
