API 2026-07 (the current stable version; no new version or retirement in the release notes up to 11 Nov 2026, https://docs.pinecone.io/release-notes/2026), Python `pinecone` 10.3.0, TypeScript `@pinecone-database/pinecone` 9.2.0, Java over the REST API with `java.net.http` and Gson 2.13.2 (the Java SDK 6.2.0 targets API 2025-10 and no newer release exists). Pins checked on 2026-11-11 against PyPI, npm and the tags of the SDK repositories. Rows are generated from `model/generated/VecDSL.ecore`: every concrete Method, Concept, AlterOperation and ExtensionItem class, then every structural feature of each Method class. Status: native (one documented API operation), concealed (the runtime composes documented operations with the exact vecDSL semantics), unsupported (Pinecone lacks it; the generator raises the message), not-applicable (cannot occur for Pinecone). No row is marked "generation pending": the query_string rewrites, sparse vector search, integrated embedding, Inference embed and rerank are generated. Rows marked "paid plan" are generated and checked against the API mock, but a free Starter project cannot run them (https://www.pinecone.io/pricing/), so the runnable full sample leaves them out. Runtime calls go through `vecdsl_pinecone_runtime.py`, `vecdslPineconeRuntime.ts` or `PineconeRuntime.java`. References point to the OpenAPI specifications of API 2026-07 at commit 7855e85 (operation in parentheses), to the SDK sources at the pinned tags, or to docs.pinecone.io.
