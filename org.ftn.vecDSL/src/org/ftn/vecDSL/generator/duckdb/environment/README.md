# DuckDB: embedded deployment

Generated by vecDSL for {{product}} {{duckdb.version}} ({{license}} license; the vss extension is {{vss.status}}).

There is no server to start. DuckDB is a library that runs inside each generated program and keeps every table, index and
schema in one database file:

- `{{storage.variable}}`: the database file. Default `{{storage.path}}` in the folder of the language (python, typescript,
  java), created on first use. An absolute path works too (Windows paths with backslashes and spaces included); `:memory:`
  opens an in-memory database that disappears with the program.
- `{{read.only.variable}}=true` opens the file read-only (writes fail).
- `{{extensions.variable}}`: a directory that holds the vss and fts extensions. Without it, each program loads them from
  DuckDB's extension directory in the user's home folder and, the first time, installs them with `INSTALL`, which downloads
  them from extensions.duckdb.org. Offline, Python takes them from the `duckdb-core-ext-vss` and `duckdb-core-ext-fts` packages
  in `requirements.txt`.
- Each program first opens an in-memory connection, loads vss and fts, enables HNSW persistence
  (`hnsw_enable_experimental_persistence`, an experimental setting: after a crash with uncommitted changes the index can be
  lost or corrupted), and then attaches the file. Loading vss before attaching is the recovery path the vss documentation
  describes for a write-ahead log that holds index changes.
- One process at a time may open the file for writing; DuckDB locks it.
- A logical database is a schema of the file.

To start over, delete the database file and its `.wal` file.

Languages:

- Python: `pip install -r python/requirements.txt` (duckdb {{sdk.python.min}}, Python >= {{python.min}}), then
  `python -u python/<program>.py`.
- TypeScript: `npm install`, `npm run build`, `npm start` in `typescript/` ({{sdk.typescript.package}} {{sdk.typescript.version}},
  Node.js >= {{node.min}}).
- Java: Maven project in `java/` with the DuckDB JDBC driver ({{sdk.java.package}} {{sdk.java.version}}, which bundles the native
  library for Windows, Linux and macOS), then `mvn compile exec:java` in `java/`.
